## About

This document summarizes the vision this project aims for.

## Overview

This project provides an agent built on the premise that it keeps running 24 hours a day, 365 days a year.

## What It Solves

With the spread of LLMs, much coding work has been replaced by agents.
As the next step, there is a growing demand for agents that run continuously without a human giving instructions.
Continuously running agents must be safe, highly extensible, and capable of supporting a wide variety of use cases.
This project aims to build such an agent.
